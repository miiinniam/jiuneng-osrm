# 玖能官网 + OSRM++ 合并重建规划

> 日期: 2026-08-04
> 状态: 待确认
> 架构决策: 统一到 Next.js 单项目（官网营销页 + OSRM++ 报价工具）

---

## 一、目标

1. **全部重新设计**玖能官网（不再用 v0.4 Braun 米灰橙风格，改用品牌标准色深蓝系）
2. **OSRM++ 植入官网**：报价工具成为官网的核心功能页面，同一项目、同一域名、一次部署
3. 保留 OSRM++ 全部能力：地图报价、车型库、口岸费用、汇率、AI 聊天、批量报价、三语

## 二、现状盘点

| 系统 | 技术栈 | 现状 |
|------|--------|------|
| 玖能官网 (jiuneng.space) | Vite + React SPA，Braun 风格 | 在线，内容完整，但"在线询价"只是线索表单（Gemini），无真实报价 |
| OSRM++ | Next.js 16 + FastAPI + Docker 3容器 | 本机未运行；报价功能完整；品牌蓝 #2563eb 与玖能标准色一致 |
| 品牌资料 | 信息表 v0.2 + 背景建设规划 | 定位"面向中国企业的工程物流平台"，标准色深海军蓝/主蓝/亮蓝/白，官网第一版中文 |

**合并基准**：以 OSRM++ frontend（Next.js）为宿主，官网营销页作为新增路由，报价工具迁移为独立路由。

## 三、路由结构设计

```
/            → 官网首页（营销落地页，锚点导航）
/quote       → 报价工具（现 page.tsx 迁移，含地图/表单/AI/结果）
/batch       → 批量报价（保留）
```

## 四、视觉设计方向（重点重设计）

**不再使用 v0.4 的 Braun 米灰+橙**，改用玖能品牌标准色：

| Token | 值 | 用途 |
|-------|-----|------|
| --brand-900 | #0f2b4a 深海军蓝 | 主背景/页脚/深色区 |
| --brand-600 | #2563eb 主蓝 | 主按钮/链接/强调 |
| --brand-400 | #60a5fa 亮蓝 | 渐变/悬停/装饰 |
| 白 #FFFFFF | — | 内容底色 |
| 灰阶 | surface-50~900 | 文本层级（沿用 OSRM++） |

**风格关键词**：工程物流平台的"专业、可靠、国际化、简约、高端"。
- 字体沿用 Geist（OSRM++ 已用），中文回退 PingFang/Microsoft YaHei
- 布局：宽屏内容区 + 克制的留白，行业数据感（数字、路线、地图元素作为签名视觉）
- 签名元素：**中越运输路线图**（一条从友谊关→河内的动态路线，贯穿 Hero 或报价入口区）——呼应"连接中越"的定位，且与 OSRM++ 地图能力天然呼应
- 动效：滚动渐显 + Hero 路线动画，克制不花哨
- 响应式：移动端汉堡菜单 + 折叠 sections

## 五、实施步骤

### Phase 1: 前端页面骨架（本机开发）
1. `frontend/src/app/page.tsx` → 改为官网首页（营销落地页）
2. 现有报价工具迁移 → `frontend/src/app/quote/page.tsx`（组件复用，仅移动路由）
3. `/batch` 保留
4. 新增官网 sections 组件（Hero/Services/Solutions/QuoteCTA/Network/Cases/CompanyInfo/Contact）
5. i18n 扩展：`zh.ts` / `vi.ts` / `en.ts` 增加官网文案字典
6. NavBar 重构：官网导航 + 工具导航合并

### Phase 2: 数据打通
7. 官网"在线报价"入口对接 OSRM++ 后端：
   - 精简报价表单（起终点搜索 + 货物参数）→ 调 `/api/v1/route/cost` 出报价 → CTA 引导完整报价页
   - 或直接 CTA → /quote 完整工具
8. 汇率/车型库等 reference 数据在官网展示（可选，如"今日汇率"角标）

### Phase 3: 后端与部署
9. CORS 增加新域名
10. 按 `deployment-vps.md` 部署到 VPS（12GB 推荐），域名规划待定

## 七、风险与注意

- v0.4 的案例/资质内容须遵循品牌信息表"已确认/已核验"口径，未授权客户名不公开
- OSRM++ 前端 Next.js 16 有 breaking changes，改代码前读 `node_modules/next/dist/docs/`
- Turbopack 在 Docker 下不监听文件变更 → 改后 `docker restart osrm-frontend` 或 touch 文件
- 报价工具地图需 Leaflet，官网首页若引地图需 dynamic import + ssr:false
