# 视觉层设计规范 — 玖能官网整合 3D 装载工具

> 用途: 回填 `website-loader-integration.md` §4.5「视觉层设计」；二期原生移植直接套用

## 1. 一期（iframe）视觉决策

| 项 | 决策 |
|---|---|
| 工具页壳 | AppShell 深蓝顶栏（navy 渐变 `#001030→#0a1b3c`）承接；页头三语标题 + 面包屑 + 「新窗口打开」入口 |
| iframe 容器 | 圆角 14px + 阴影 `0 10px 30px rgba(0,16,48,.08)` + 顶栏模拟浏览器 chrome（红黄绿点 + URL 条），min-height 900px |
| 工具本体 | Carbox 深色工程风一期**原样**，不强行换肤（保持零改动、风险最低） |
| 首页双卡 | 卡片白底 + 顶部 3px 青蓝渐变线；运费报价卡 → `/quote`（品牌蓝按钮），3D 装载卡 → `/tools/loader`（信号青按钮，区分主次入口） |
| 报价 CTA | 映射命中 → 品牌蓝实心按钮「📦 用此车型去 3D 装柜」带 `?vehicle=`；未命中 → 不渲染（避免死链） |

## 2. 二期 token 映射规范（Carbox 深色工程风 → 官网 navy/brand-blue 体系）

### 2.1 色板映射

| Carbox 现状 (index.html/scene3d.js) | 官网 token (globals.css) | 说明 |
|---|---|---|
| `--bg: #14171c` 场景底 `#101318` / `#1c1f24` | `--navy-950: #00081a` / `--navy-900: #001030` | 场景背景用最深 navy，保留 3D 深色沉浸感 |
| `--panel: #1d2229` | `--navy-mid: #0a1b3c` 降透明度 | 面板毛玻璃：`rgba(10,27,60,.92)` + blur |
| `--border: #2c333d` | `rgba(255,255,255,.08)` / `--brand-200` | 边框统一白色低透明或品牌蓝弱化 |
| `--accent: #4da3ff` | `--cyan: #2080f8` / `--brand-500` | **主操作色统一为信号青**（选中、按钮、链接、幽灵框） |
| `--green: #2ecc71` | 保持 `#2ecc71`（语义色，跨品牌通用） | 装载率/超重/合法落位绿 |
| `--orange: #f39c12` `--red: #e74c3c` | 保持（语义色不变） | 预警/超重/非法红 |
| 车头涂装 `#3a6ea5` / `#55677a` | 保留（3D 模型语义色，不参与 UI 主题） | 3D 资产色独立于 UI token |

### 2.2 结构映射

| Carbox 区域 | 二期原生位置 |
|---|---|
| 顶部工具条 | 复用 AppShell Header（深色态），工具专属按钮收进工具条右侧 |
| 右侧面板（车型/货物/统计） | 保持右侧抽屉布局，样式换 brand 体系；折叠逻辑保留 |
| 悬浮统计圆环卡 | 保留（信息密度高），border/阴影换品牌 |
| 底部提示胶囊 | 保留，文字换三语 i18n |

### 2.3 三语规则

- 壳层（标题/面包屑/CTA/首页区块）：走现有 i18n 契约（zh/vi/en）
- 工具内文案（按钮/提示/车型名/货物标签）：二期抽入 `src/lib/i18n`，与现有字典同构；一期 iframe 内中文
- 车型名映射建议：Carbox 预设名直接复用 OSRM++ 31 车型库的三语名（二期打通车型库时顺带完成）

### 2.4 布局红线

- 工具页保持全高工作区（左 3D / 右面板），不塞进窄卡片；移动端二期单独适配（一期 iframe 内横向滚动可接受）
- iframe 期不修改 Carbox 任何 CSS（零改动原则）；视觉统一全部在二期原生层完成
